# GenCode 路线图

> 一期（平台底座）已完成。以下按里程碑推进，每个里程碑交付可运行的完整闭环。

## 一期 ✅ 平台底座（当前）
Sa-Token 登录认证（验证码/锁定/互斥登录/登录日志）、用户/角色/菜单/部门/租户/字典/参数管理、
操作日志切面、菜单+按钮+接口三层权限、多租户字段隔离、多模块脚手架、Flowable 接入位、
OpenAPI 文档、前端管理端（登录/布局/仪表盘/9 个系统页面）。

## 二期 表单与列表（低代码核心闭环）
- 元数据表：`lc_app`、`lc_page`、`lc_form_schema`、`lc_list_schema`、`lc_obj`（对象/字段）、版本与发布（发布=Schema 快照，支持回滚）。
- 表单设计器：拖拽栅格布局 + 30+ 组件（输入/选择/日期/上传/子表/布局容器…）、联动规则（显隐/赋值/禁用/必填）、校验（非空/长度/手机/邮箱/区间/正则）、字典与远程接口下拉。
- 表单渲染引擎：JSON Schema → AntDv 组件树，规则引擎执行联动。
- 列表设计器：列配置/搜索栏/操作按钮/树表/合计行，数据源=单表/SQL 数据集/自定义接口。
- 动态 SQL 引擎：拖拽条件 → 参数化 SQL（防注入），分页/排序/区间/模糊。
- 运行时页面：`/app/:pageCode` 按发布版本渲染，权限绑定（按钮级）。
- 交付闭环：建表/选表 → 设计表单+列表 → 绑定权限 → 发布 → 运行 → 日志。

## 三期 流程引擎（Flowable 深化）
- BPMN 可视化设计器（bpmn-js 定制：人工/抄送/条件/并行/子流程节点）。
- 节点审批人（直属领导/角色/指定人/部门负责人），会签/或签/驳回/转审/加签。
- 表单绑定 + 条件分支按表单字段路由；发起/待办/已办/抄送/撤回/终止；审批轨迹+签名。
- 与表单设计器打通：流程表单一键引用已发布表单 Schema。
- 数据权限落地（data_scope 在流程待办/业务查询中生效）。

## 四期 报表与大屏
- 数据集（SQL/API/对象）、参数、定时刷新。
- 报表设计器（交叉表/分组统计/导出 Excel）、图表组件（折线/柱/饼/雷达/地图/进度）。
- 大屏设计器（拖拽+自适应+轮询）、打印模板（单据/小票/A4）。

## 五期 数据管理与代码生成
- 可视化建表（DDL 预览/逆向工程/结构对比）、多数据源管理（连接测试/加密/连接池监控）。
- 代码一键生成：Java（Entity/Mapper/Service/Controller）+ Vue CRUD，吸收
  `ZCodeProject/flow-codegen-server`：五方言（MySQL/PG/Oracle/SQLServer/达梦）保留字转义、
  雪花 ID、DDL 映射、zip 下载。
- 数据导入导出（导入校验+错误回显）、数据脱敏、回收站。

## 六期 集成、可观测与生产化
- 第三方 HTTP 接口管理（参数映射/鉴权/重试/Mock）、Webhook、SSO（钉钉/企微/飞书/OAuth2）。
- Redis 全面接入（Sa-Token/缓存/验证码）、Quartz/XXL-Job 可视化、MinIO/OSS 文件。
- 消息中心/公告/国际化；监控告警（Actuator+Prometheus+Grafana+SkyWalking）。
- Docker 镜像、K8s/Helm、CI/CD 流水线；国产库（达梦/金仓）驱动与方言实测。
